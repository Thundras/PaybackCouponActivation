# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public issue.

Report it privately via [GitHub Security Advisories](https://github.com/Thundras/PaybackCouponActivation/security/advisories/new).

## Scope

This project automates coupon activation on a personal PAYBACK account. It stores a browser session in `user-data/` (excluded from version control). No credentials are stored in the repository.
